Parcial C1 - Ciencia de Datos
1. Tipos de datos y su clasificación
Tipo de dato	Ejemplo	Clasificación
Tabla de ventas de una tienda	Datos ordenados en filas y columnas (producto, cantidad, precio)	Estructurado
Perfil de usuario en formato JSON	Información con cierto orden pero sin una tabla fija	Semiestructurado
Videos subidos a una plataforma como YouTube	No tienen una forma ni columnas fijas	No estructurado
Comentarios de clientes en una encuesta	Texto libre escrito por cada persona de forma distinta	No estructurado
2. Preguntas de analítica

Pregunta descriptiva: ¿Cuál fue el producto más vendido en la tienda el año pasado?

Pregunta predictiva: ¿Cuántas unidades del producto más vendido se venderán el próximo mes?

3. Diagrama del proceso de datos
Fuente  →  Almacenamiento  →  Análisis  →  Visualización
Etapa	Descripción
Fuente	Datos crudos: encuestas, sensores, redes sociales
Almacenamiento	Base de datos o la nube
Análisis	Se procesan los datos y se sacan conclusiones
Visualización	Gráficas, tablas o dashboards
4. Descriptive vs Predictive Analytics

Descriptive analytics looks at data from the past to understand what already happened.

Predictive analytics uses that same data to try to guess what could happen in the future.
