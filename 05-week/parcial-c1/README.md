1. Tipos de datos y su clasificación
Tipo de dato	Ejemplo	Clasificación
Tabla de ventas de una tienda (Excel con producto, cantidad, precio)	Datos ordenados en filas y columnas	Estructurado
Archivo JSON con el perfil de un usuario de una app (nombre, likes, amigos)	Tiene cierto orden pero no es una tabla fija	Semiestructurado
Videos subidos a YouTube	No tienen una forma fija ni columnas	No estructurado
Correos o comentarios de clientes en una encuesta	Es texto libre, cada persona escribe distinto	No estructurado

(Nota: si tu profe pide variedad, puedes cambiar el último por "logs de un servidor" y ponerlo como semiestructurado, ya que tienen fecha y hora pero el mensaje es libre.)

2. Preguntas de analítica
Descriptiva: ¿Cuál fue el producto más vendido en la tienda el año pasado?
Predictiva: ¿Cuántas unidades del producto más vendido se venderán el próximo mes?
